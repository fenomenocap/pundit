# Ask

The endpoint behind Pundit's chat. Sends a natural-language question, gets back a model-grounded analysis of a specific fixture.

### `POST /api/ask`

**Rate limit:** 10 requests/minute per client (tighter than the rest of the API, since this calls out to an LLM).

**Request body:**

```json
{
  "question": "France vs Morocco"
}
```

You must name two teams that have a confirmed fixture against each other; Pundit matches on team names appearing in the question text. If it can't identify two teams, or can't find a fixture between them yet (e.g. an undetermined knockout matchup), it returns a `400`/`404` with a plain-language error instead of guessing.

**Response:**

```json
{
  "answer": "France go in as clear favourites here...",
  "grounding": {
    "date": "2026-06-15T18:00:00Z",
    "stage": "group-stage",
    "home": "France",
    "away": "Morocco",
    "pHome": 0.62,
    "pDraw": 0.22,
    "pAway": 0.16,
    "stakePHome": 0.58,
    "stakePDraw": 0.24,
    "stakePAway": 0.18
  }
}
```

* `answer` — plain-language analysis (2–4 short paragraphs): headline win/draw/win and over/under 2.5 read, 1–2 likely scorelines, and what the underdog would need. Generated by Claude, grounded in `grounding` and, when relevant, a live web search for current injury/squad/form news.
* `grounding` — the exact model + market data the answer was generated from, so you can verify the numbers behind the analysis yourself. Same shape as an entry from [`GET /api/model/fixtures`](model.md).

This endpoint does not accept or store any personal data — only the question text.
