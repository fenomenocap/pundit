# Dossier evidence captures

Raw federated-search outcomes and per-URL verification logs for sample builds.

Generated by:

```bash
OPENROUTER_API_KEY=… pnpm exec tsx packages/api/scripts/capture-verified-dossier-samples.ts
```

Each file: `docs/dossier/captures/{fixtureId}/{as_of}.json` with `search[]`, `verifications[]`, and `summary`.

Only rows with `outcome: "verified"` (HTTP 200 + on-page claim check) appear in committed dossier samples.
